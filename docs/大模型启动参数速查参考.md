# 启动器模型参数清单（llama.cpp b9982 / GTX 1060 6GB）

> 来源：`launcher_main.ps1`（2026-07-14 版）`Get-Models` 函数实测代码。
> 启动器固定前缀（自动拼接，**不在各模型 customArgs 内**）：
> - `-m <模型完整路径>`
> - `--port 8081`
> - `--host 127.0.0.1`
> - 视觉模型额外自动拼接 `--mmproj <对应 mmproj 路径>`（按文件名探测）

> 其余参数均为启动器硬编码的固定值。菜单里共 **7 个可启动模型**，
> `Qwen3-0.6B` 与 `Qwen3.5-0.8B` 被代码显式跳过（仅作 draft 用，不单独部署）。
